# Moses Portfolio Website

A personal portfolio website built as a class project showcasing my journey as a web developer and my interests in sports, gaming, and technology.

## Overview

This is my final IT class project—a multi-page website that introduces myself, my interests, and the technical skills I've learned. The site demonstrates my understanding of HTML structure and CSS styling while serving as a living portfolio of my work.

## Features

- **Responsive Design**: Mobile-friendly layout that adapts to different screen sizes
- **Multi-Page Structure**: Home, About, and Projects pages with consistent navigation
- **Professional Layout**: Clean, organized design with card-based layouts
- **Image Integration**: High-quality images showcasing interests and personal profile
- **CSS Styling**: Custom stylesheet covering colors, spacing, typography, and responsive design

## Technologies Used

- **HTML5**: Page structure and semantic markup
- **CSS3**: Styling, layout, and responsive design
- **Images**: JFIF format for photos and visual content
