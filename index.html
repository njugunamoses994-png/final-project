I am Moses, a student at Lenana School. This site is my personal portfolio and class project. It shows who I am, how I built the pages, and the ideas I want to work on next.

How I built the site

I used what I learned in my IT classes: HTML for the structure of each page and CSS for colour, layout, and spacing. I worked on a laptop and practised by turning class examples into my own pages.

After feedback, I put every page on one stylesheet, stretched the content across the screen, and wrote more about myself so the site is easier to understand.

Challenges and how I tackled them

Lack of knowledge

I still had a lot to learn, so I used my IT lessons, practised the tags we were taught, and built this site as a real project instead of only reading notes.

Errors

Broken tags and missing pieces made pages look wrong. I checked the HTML structure, fixed extra or missing tags, and opened the site in the browser to see what still needed work.

Lack of understanding

When something did not make sense, I broke it into smaller steps and used feedback from others. That is why this version has a biography, clearer layout, and solutions next to each challenge.
